## 1. Purpose

Trang này là **trang hướng dẫn đọc tài liệu cho thành viên mới** trước khi đi sâu vào từng project như **BDMA** hoặc **DCAM**.

Mục tiêu của DVID Read Guide là giúp developer, QA, PM và technical lead mới hiểu trước:

Tư duy vận hành OSd của team.

Cách team chia requirement thành Epic / Feature / User Story / Task.

Cách viết và đọc task development.

Workflow chuẩn trên Jira.

Workflow chuẩn khi làm việc với Git.

Sau khi hiểu các tài liệu nền này, thành viên mới mới nên đọc project-specific documents như BDMA Project Home hoặc DCAM Project Home.

## 8. Operating Principles

Principle

Description

Documentation First

Thông tin quan trọng nên được ghi vào Confluence thay vì chỉ nằm trong chat.

Jira First for Work

Công việc cần làm nên được ghi nhận trên Jira trước khi thực hiện.

Clear Acceptance Criteria

Task phải có điều kiện nghiệm thu rõ ràng trước khi đưa vào sprint.

Pull Request Review

Thay đổi code quan trọng cần đi qua pull request và review.

Update Docs When Scope Changes

Khi requirement, technical design hoặc release scope thay đổi, tài liệu liên quan cần được cập nhật.

Decision Tracking

Quyết định quan trọng nên được ghi lại để team và AI có context về sau.

Practical over Perfect

Tài liệu không cần dài, nhưng phải đủ rõ để người khác hiểu và tiếp tục công việc.
