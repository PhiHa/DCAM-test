## 1. Purpose

Trang này là **trang chủ điều hướng** cho toàn bộ tài liệu dự án **BDMA**.

Mục tiêu của Project Home là giúp PM, Product Owner, Developer, QA, Technical Lead và các bên liên quan nhanh chóng biết:

Cấu trúc tài liệu hiện tại của dự án BDMA.

Tài liệu nào đã có.

Tài liệu nào thuộc Product Management, Sprint Operations, KPI Reports, Technical Documentation, Release Management, Incident Log hoặc Decision Log.

Nên đọc tài liệu theo thứ tự nào.

Những tài liệu nào cần được ưu tiên cập nhật hoặc chuẩn hóa tiếp theo.

textwide760## 9. Documentation Maintenance Rules

Rule

Description

Keep Project Home Updated

Khi tạo, đổi tên hoặc di chuyển tài liệu quan trọng, cần cập nhật trang này.

Single Source of Truth

Mỗi loại thông tin nên có một tài liệu chính chịu trách nhiệm.

Cross-link Documents

Các tài liệu liên quan cần link qua nhau để dễ điều hướng.

Link Jira When Possible

Task, feature, release hoặc incident quan trọng nên được liên kết với Jira issue tương ứng.

Update Before Release

Tài liệu liên quan nên được cập nhật trước mỗi release.

Use Consistent Naming

Tên tài liệu nên thống nhất: BDMA + module/feature + document type.

Review Cadence

Project Home nên được review sau mỗi milestone hoặc major release.
