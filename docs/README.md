# DCAM documentation

This directory separates Confluence-derived knowledge from repository-local developer notes.

## Folders

- [dcam-knowledge](dcam-knowledge/README.md) is the local mirror/summary of the DCAM Confluence space. Confluence remains the source of truth.
- [local-dev](local-dev/README.md) is for local repository state, evidence, plans, and other developer notes that are not Confluence pages.

Keep new local implementation notes out of `dcam-knowledge` unless they summarize a Confluence page or record its source inventory.
