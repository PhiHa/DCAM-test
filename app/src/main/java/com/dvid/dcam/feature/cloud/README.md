# Cloud

Trạng thái: planned feature, chưa implement.

Feature này dành cho các nghiệp vụ liên quan đến đồng bộ, upload hoặc nhận cấu hình từ hệ thống server/cloud.

Khi bắt đầu implement, thêm code theo cấu trúc:

```text
cloud/
├── domain/
├── application/
│   ├── usecase/
│   └── port/
└── presentation/     nếu feature có UI state riêng
```
